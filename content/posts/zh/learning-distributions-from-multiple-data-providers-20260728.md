# Learning Distributions from Multiple Data Providers

> 来源: [arXiv](https://arxiv.org/abs/2607.24732v1)

作者: Jon Kleinberg, Amin Saberi, Xizhi Tan 等

Motivated by learning from heterogeneous and overlapping data providers, we study a stylized model of distribution learning from restricted conditional samples. The goal is to learn an unknown distribution $p$ on a finite domain $[n]$. The learner is given a fixed family of queryable sets $\mathscr{S} \subseteq 2^{[n]}$, and each query to $S \in \mathscr{S}$ returns an independent sample from the conditional distribution $p(\cdot \mid S)$.
