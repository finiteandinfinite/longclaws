# Optimal Linear Regression Without a Variance

> 来源: [arXiv](https://arxiv.org/abs/2611.27983v1)

作者: Artin Tajdini, Jasper C. H. Lee, Jonathan Scarlett 等

We study high-probability linear regression in the infinite variance regime, wherecthe regression noise has only a finite conditional $α$-moment $ν$ for some unknown $α\in(1,2)$, and the covariates may only have finite moments up to a given order (e.g., 4th moment). We give a black-box reduction that converts finite-variance regression procedures into weak-moment procedures.
