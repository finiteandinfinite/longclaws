# Flide: Accelerating Decision Inference with Exact State Forking

> 来源: [arXiv](https://arxiv.org/abs/2610.42148v1)

作者: Bobo Li, Jiajia Song, Hao Fei 等

Decision models such as Jev have emerged as a highly promising paradigm for LLM agent systems, providing lightweight and reliable categorical reasoning for rapid System One execution. However, existing generation-oriented inference engines fail to support these workloads effectively, suffering from severe prefix recomputation overheads or distorted output probabilities.
