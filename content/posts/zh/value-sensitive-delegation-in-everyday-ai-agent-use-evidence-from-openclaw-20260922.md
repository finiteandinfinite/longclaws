# Value-Sensitive Delegation in Everyday AI Agent Use: Evidence from OpenClaw

> 来源: [arXiv](https://arxiv.org/abs/2609.22067v1)

作者: Renkai Ma, Ruyuan Wan, Xuan Lu 等

Users increasingly delegate work to autonomous AI agents, yet evaluations typically measure task completion rather than the values users prioritize. Using Value Sensitive Design, we analyzed, with LLM assistance, 73,093 first-person Reddit posts about using OpenClaw, each for its human value, agent aspect, value fulfillment, and user outcome.
