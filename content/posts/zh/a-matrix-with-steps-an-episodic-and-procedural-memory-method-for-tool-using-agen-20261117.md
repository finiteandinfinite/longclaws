# A Matrix with Steps: An Episodic and Procedural Memory Method for Tool-Using Agents and Robots

> 来源: [arXiv](https://arxiv.org/abs/2611.20230v1)

作者: Jürgen Paulhart, Peter Schüller

Agents that call tools and robots that execute tasks are challenged by two shortcomings: they repeat what failed before, and they learn from runs that they only believe succeeded. We describe the construction of a memory that addresses both, built for a production agent platform. Every run is recorded as an episode, and only an outcome confirmed by an external check, a test, a tool result or a person counts; the agent's own claim never does.
