# Long-WAM: Scaling the Context of World-Action Models

> 来源: [arXiv](https://arxiv.org/abs/2610.10528v1)

作者: Wei Huang, Bohan Zhang, Chenzhi Liu 等

Real-time robot control demands enough visual history to infer motion and task progress, but processing that history can delay action. We present Long-WAM, a model-system framework for scaling the context of causal world-action models under real-time control constraints. Our central finding is that access to history is not the same as using it: longer histories pay off far more when the video foundation is pretrained autoregressively (AR).
