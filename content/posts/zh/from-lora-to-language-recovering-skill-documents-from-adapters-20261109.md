# From LoRA to Language: Recovering Skill Documents from Adapters

> 来源: [arXiv](https://arxiv.org/abs/2611.09454v1)

作者: Saranya Dintakurthy Swadha, Pavan C Shekar, Arpit Jain 等

Agent skills are short documents that teach a language model how to handle a class of tasks. To save context, these documents are increasingly compiled into low-rank adapters (LoRA), which keep the behaviour but lose the text: an adapter is hard to read, edit, audit or move to another model. We ask whether the skill document can be written back from the adapter and its frozen base model, and we score each recovered document by the share of the original's key instructions it states and by the tas
