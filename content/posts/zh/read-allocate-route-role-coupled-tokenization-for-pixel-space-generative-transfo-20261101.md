# Read, Allocate, Route: Role-Coupled Tokenization for Pixel-Space Generative Transformers

> 来源: [arXiv](https://arxiv.org/abs/2610.40647v1)

作者: Jiongfan Yang, Weichen Fan, Haiwen Diao 等

Pixel-space generative Transformers typically use one token per image patch, so capturing finer detail requires more tokens and makes global attention increasingly expensive. We observe that finer detail does not necessarily require more global communication: low-frequency structure benefits from global exchange, while high-frequency detail can be modeled locally.
