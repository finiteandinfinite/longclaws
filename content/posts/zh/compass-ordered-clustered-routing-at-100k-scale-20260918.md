# COMPASS: Ordered Clustered Routing at 100K Scale

> 来源: [arXiv](https://arxiv.org/abs/2609.20352v1)

作者: Ido Greenberg, Hugo Linsenmaier, Piotr Sielski 等

Large-scale routing often requires visiting clusters of nodes in a prescribed order, giving rise to the Ordered Clustered Traveling Salesman Problem (OCTSP). Optimizing each cluster independently seems natural, but misses non-local dependencies. We introduce the COMPASS algorithm for OCTSP, which combines search with learning-accelerated routing by orchestrating parallel sub-solvers. COMPASS has no quality ceiling and its solutions keep improving with compute. It exploits the clustered structure
