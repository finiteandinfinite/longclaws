# CPU-ARC: Agentic Reasoning Caching for on-CPU Reasoning Reuse

> 来源: [arXiv](https://arxiv.org/abs/2611.09891v1)

作者: Peter Belcak, Greg Heinrich, Saurav Muralidharan 等

Large language models reinvent the wheel all the time. They conflate task-solving with the execution of the solutions, which forces them to solve every problem from scratch. We show that once a task has been reasoned through, the application of its solution to a new problem instance can be done very efficiently and with little involvement from language models.
